Konfigurator przycisków
Status: niepołączono
Button Box nie jest w trybie konfiguracji Aby wejść w tryb konfiguracji:
  1. Odłącz Button Box od USB.
  2. Przytrzymaj jednocześnie CZUWAK i ŚRODKOWY.
  3. Trzymając oba przyciski, podłącz Button Box do USB.
  4. Poczekaj, aż Button Box uruchomi tryb konfiguracji.
  5. Następnie kliknij ponownie „Połącz z Button Box”.
