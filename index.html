Button Box EN57

Konfigurator przycisków
Status: niepołączono
Button Box nie jest w trybie konfiguracji Aby wejść w tryb konfiguracji:
  1. Odłącz Button Box od USB.
  2. Przytrzymaj przycisk CZUWAK.
  3. Cały czas trzymając CZUWAK, podłącz Button Box do USB.
  4. Trzymaj CZUWAK przez co najmniej 3 sekundy od podłączenia USB.
  5. Puść przycisk CZUWAK.
  6. Kliknij ponownie „Połącz z Button Box”.
Button Box jest w trybie konfiguracji.
